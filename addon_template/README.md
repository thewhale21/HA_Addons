# Home Assistant Add-on: Add-on Template

A starting point for a Home Assistant add-on with its own web page.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

It runs as is: install it to see the web page in the sidebar, pick an
entity on the Settings tab and watch it on the Overview. Then make it your
own: see [DOCS.md](DOCS.md).

To start a new add-on from it, run `python scripts/new_addon.py` at the top
of the repository (see the repository's README).
